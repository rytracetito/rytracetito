### 🔬 Current research

**PhD thesis (since Oct. 2026):** *Goodness-of-fit tests for degradation processes with or without imperfect maintenance.*
Supervised by Christian Paroissin (LMAP, Pau) and Franck Corset (Laboratoire Jean Kuntzmann, Grenoble).

Before relying on a degradation model to plan maintenance, we must check that it actually describes the data.
I develop goodness-of-fit tests for **Gamma** and **Wiener** processes, first without maintenance, then when imperfect maintenance actions (e.g. ARD models) partially reduce the degradation of a system.

🧪 **Try it live:** an interactive degradation simulator (Gamma / Wiener, failure threshold, imperfect maintenance, Monte Carlo) runs on [my website](https://rytracetito.github.io/#labo).
